## 🚀 Key Improvements Made in Redesign

1. **Modern Aesthetic & Dynamic UI/UX**:
   - Designed a luxury **Royal Navy (`#0f172a`) & Gold (`#d97706`) palette** with glassmorphism, subtle micro-interactions, responsive typography, and full dark/light theme switching.

2. **Interactive Campus Virtual Tour**:
   - Built a filterable 30-acre campus facility gallery with lightbox modals showcasing STEM Robotics Labs, Olympic Swimming Pools, Digital Libraries, and Science Arenas.

3. **Smart Fee Calculator & Admission Flow**:
   - Developed an instant interactive tuition & transport fee estimator allowing parents to calculate total annual costs based on grade level, optional transport, and dining services.

4. **K-12 Academic Curriculum Explorer**:
   - Created tabbed program pathways (Pre-Primary, Primary, Middle, Secondary, Senior Secondary) featuring core subjects, pedagogical highlights, and downloadable curriculum cards.

5. **Integrated Student & Parent ERP Portal Demo**:
   - Built an interactive modal displaying live timetable schedules, attendance tracking, grade reports, and digital notice bulletins for parents and students.

6. **Events & Press Center**:
   - Integrated filterable event cards (Science & AI Expo, Swimming Meet, MUN Conference) with an interactive "Visitor Registration" modal and WhatsApp bulletin subscription.

7. **Faculty & Leadership Directory**:
   - Added a live search and department-filtered faculty showcase detailing educators' credentials, PhD degrees, and direct office contact buttons.

8. **Fully Responsive & Accessible**:
   - Engineered seamless layout scaling across Mobile, Tablet, Laptop, and Desktop screens with WCAG compliant contrast ratios and mobile navigation drawers.

## 💻 Local Setup Instructions

1. **Clone the repository**:
   ```bash
   git clone https://github.com/dettroin-developer/DETTROIN-INT-Applicant-Website.git
   cd DETTROIN-INT-Applicant-Website
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

4. **Build for Production**:
   ```bash
   npm run build
   ```
